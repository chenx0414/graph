# Implement and verify

- Work only inside the confirmed scope; do not silently widen acceptance.
- Prefer small, reviewable changes that keep the project runnable.
- Run the confirmed checks and attach real outputs or artifact digests.
- Report blockers with the exact command, error and affected files.
- Never edit confirmed acceptance checks or fabricate evidence.
