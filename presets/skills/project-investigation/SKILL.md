# Project investigation

- Read code, configuration and recorded evidence before asking anything.
- Ask only questions whose answers change the plan; state what is already known.
- Separate observed facts from assumptions and label each clearly.
- Never modify business files, run implementation commands, or claim work is done.
- Summarize findings as a short list of evidence, unknowns and options.
