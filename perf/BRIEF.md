# 开工简报：Graph App 提速

## 核心操作

1. 打开 App 到 Main 会话可用：启动应用 → Main 会话转录可见、输入框可用。
2. Main 会话的周期刷新：应用每 3 秒拉一次当前会话，刷新期间不能卡 UI。
3. 打开「编队」页到 Agent/任务列表可见。

## 什么叫「能用」

- 启动/切换会话：转录出现，不是「正在读取会话…」或骨架。
- 刷新：`/api/conversations/{id}` 返回完成，旧帧不被替换成空白。
- 编队页：Agent 列表与统计数字出现，不是「正在读取编队…」。

主指标：`GET /api/conversations/{main}` 的 p75（它是 Main 可用前的阻塞调用，也是 3 秒刷新调用的接口）。
辅指标：`GET /api/fleet` 的 p75。

## 不能动

- 视觉、交互、文案不变。
- 现有测试、`scripts/check-queue.py` 全绿。
- 会话/成本/用量/token 统计数字口径不变（有测试的按测试；没有的写用例钉住）。
- 不引入新的前端依赖或网络请求。

## 目标

主指标 p75 降低 50% 以上；先证明代理计数（每次 View 加载的 invocation 行数、JSON 解码次数）与真实耗时同向，再用它爬山。

## 上线

本仓库为本地 App；改动以 commit 落地，App 重建安装后真机复验。回滚：revert 对应 commit。
