# 优化前基线

2026-10-16，基于开始任务时的整个工作区（包含已存在的未提交 UI/provider 修改），构建存于 `/tmp/graph-flash-baseline-web`。不是干净 HEAD，因此不能拿 HEAD 构建冒充相同基线。源码基线未提交，临时构建应在机器清理前保存。

原始数据：[baseline.json](bench/baseline.json)。两份相同基线交替各 10 次，用于校验测量稳定性。Chromium、1440×960、全请求 Fast 4G、冷上下文，真实 SQLite/HTTP 服务；没有代理、没有模型网络调用。分位数用 nearest-rank。

| 操作 | p50 | p75 | p95 |
| --- | ---: | ---: | ---: |
| 导航到编辑器接受文字 | 2999ms | 3008ms | 3012ms |
| 点击会话到编辑器接受文字（初版脚本） | 103ms | 104ms | 109ms |
| 路由到 Graph、节点/边可见并可点击 | 116ms | 117ms | 127ms |

初版会话终点没有显式等待历史消息。最终脚本增加持久化历史消息可见条件，只使用最终配对 A/B 比较，不拿旧会话数字计算收益。

首屏关键资源：主 JS 1,260,114 字节，下载结束约 2913ms；CSS 155,670 字节，约 698ms；其余 3 个 JS 共 9,311 字节。主 JS 是限速条件下的主要阻塞。1.1MB 标志图片是 CSS 背景；可输入终点不等待图片，不将图片占位当作已完成内容。

本地桌面无公共站点，无 CrUX。这里不测模型响应速度，不把暖守护进程上的浏览器导航当作 Electron 冷启动。
