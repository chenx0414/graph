# Triage Labels

这套技能用**五个规范分诊角色**说话；本文件把角色映射到本仓库实际使用的标签串。

| 规范角色（mattpocock/skills） | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等维护者评估 |
| `needs-info` | `needs-info` | 等报告者补信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人来做 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色（例如「打上 AFK-ready 的分诊标签」）时，用本表右侧对应的标签串。

右侧那列就是本仓库的词汇表：改这里的串，让技能跟着你的标签走，而不是新建重复标签。
