# 2026-10-20 基线整合

本轮按使用者要求，将当前 Go APP、近期界面与用量修复、已交付的 pi-durable 分支整合到 main。运行边界见 [ADR 0032](../adr/0032-go-backend-shared-durable-host.md)。重复或已被新实现替代的分支以最终实现为准；旧诊断输出、过期构建及临时工作副本不作为产品源码保留。

## 代码与验证

- main 和 graph 节点通过同一 durable SDK 宿主运行；旧 TS worker 及 Go 移植中的旧 worker/进程循环退役。
- Go E2E 验证真实工具读取、相同 SDK 会话跨重启保留、SDK 完成而 Graph 确认写入失败后的收据恢复，以及再次重启零重复请求。新增 Go 主进程和节点 SIGKILL 验证覆盖：SDK 受理后尚未发送、完成后业务 ACK 失败、保持原 execution/attempt/submission、显式恢复不重复调用；恢复前修改模型上限时继续使用冻结原配置，后续新对话采用更新配置。
- 修复 Go 与 SDK 共用 SQLite 时的锁等待；恢复保留原操作和未知事实，完全访问策略不释放未知派发。
- OpenRouter 桌面授权、取消、拒绝、重复回调、安全存储、重启模型调用和撤销经过真实 Electron 验证。
- 将 Anthropic 完整/更新/截断/错误 delta/缺失输出用量 E2E 切到真实 Go 进程；完整累计证据才可权威计费，容量拒绝保持未知用量。
- 构建与打包统一携带 Go 二进制，常规 check 同时执行 Go 构建、vet 和既有门禁。普通截图保存在临时目录，既有交付证据保持不变。

独立旧分支中的上游 subagent 调研保留在 `docs/archive/pi-subagent-research/`；旧 Graph 诊断脚本采用 main 已改进的实现，临时审查输出留在 Git 历史与清理前源码快照。2026-10-20 完整 `node --run check` 通过：278 文件，1543 项通过、3 项沿用既有环境条件跳过；验收证据不变。macOS APP、DMG 与产物核对均通过。正式数据只读验证解析 125 份 main 历史、4573 条有效上下文消息；已导入的 119 份原文件摘要未变化。正式数据库副本被动迁移与重复迁移通过：129 个 main 对话中 126 个有历史的对话映射到 durable，3 个空会话保持未初始化；47694 条消息摘要迁移前后逐字节一致。切换前数据库备份通过 SQLite quick_check。正式 APP 已切到主检出的 main，并在真实桌面恢复原对话；Go、共享 durable 宿主、HTTP 首页和启动信息均已核对。TS 中仍被前端、SDK、迁移历史 reader 或现有参考验证使用的模块继续保留；源码删除以活跃引用和验收覆盖为依据。

## 分支工作归并依据

Go 与 durable 以真实代码合并；其余分支保留全部提交祖先。Matt 团队和节点指令采用 main 已集成的新实现；诊断脚本采用 main 较新的版本，临时审查输出不再作为产品文件。独立上游调研与动态改图实测记录移入 `docs/archive/`，绑定旧 graph 与本机数据库的一次性门不恢复为当前测试入口。临时混合构建与旧 worker 实现由新基线取代。私有标记修复采用当前解析实现，原提交同时纳入祖先，避免清理工作副本丢失历史。
