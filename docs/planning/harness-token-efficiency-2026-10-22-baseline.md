### 2.4 压缩的真实行为

- 86 次成功压缩、111 次启动、**9 次失败**（6 次因为"生成撞到 token 上限、摘要不完整"）。
- 压缩前 token 中位 **495,979**（= 上下文窗口 512,000 − 预留 16,384），压缩后中位 **27,158**。
- 也就是说：会话在两次压缩之间把上下文从 27K 长到 496K，**这段里的每一次请求都重新付费整段前缀**。

### 2.6 会话上下文里装的是什么（对话 3303 的真实记录）

主会话的 durable transcript 共 1,090,255 字符（约 272K token）：

| 角色 | 字符 | 占比 |
| --- | ---: | ---: |
| toolResult | 539,655 | 49.5% |
| assistant | 319,134 | 29.3% |
| user（任务说明包） | 218,006 | 20.0% |

工具结果里 `bash` 占 34.9%（全局），`apply_rsi_change` 7.2%，`artifact_promote` 3.8%，`artifact_publish` 3.5%。

**任务说明包（briefing）是 62 份，每份约 3,500 字符，其中 89.5% 与上一份逐字相同**（实测相邻两份的公共后缀 3,131 字符）。也就是说 218,006 字符里约 194,000 字符是同一段文字重复了 62 遍，而它每一遍都被后面的每个请求重新读一遍。

工具结果的体积分布反而是平的：979 条结果，中位 247 字符、p90 1,309、最大 55,102；超过 2,000 字符的只有 18 条（占工具结果字节的 22.6%）。ANSI 转义序列与行号前缀合计只占工具结果的 1.6%（占全局 0.8%）——**"把大输出落盘"这条杠杆在本机上只有约 8% 的上下文可省，远小于任务说明包的重复**。

### 2.7 工具错误的分类（记录在案的全部 188 条）

目标书要求把工具错误分成"预期的"和"harness 的缺陷"，后者才是要修的。按真实 transcript 逐条分类：

| 类别 | 条数 | 占比 | 典型 |
| --- | ---: | ---: | --- |
| **预期** | ~161 | 86% | 路径越界 / 路径受策略保护（27）、用户暂停或中止（37）、浏览器扩展起不来或忙（36）、MCP 缺 task grant（7）、参数写错（缺 graphId、缺 path、edits 定位不到、schema 不是 kind@version）、幂等与并发护栏（requestId 复用、artifact head 变了、重复提交） |
| **harness 缺陷** | 14 | 7% | 三个同源：**宿主在工具还在飞的时候关了**——"Plugin helper is closed"（7）、"Pi host channel closed"（2）、"Runtime is closed"（2）；外加工具结果计数器的原子写 ENOENT（5，已在 2026-10-10 审计里单独修过） |
| 环境/外部 | ~13 | 7% | 浏览器临时 profile 目录无权（11）、沙箱 spawn EPERM（2）、SDK 损坏（2）、网络 fetch failed（1） |

**能修的几类里，三类是同一个竞态**：宿主在工具调用还在飞的时候被关掉，模型收到的是一句它无法据此行动的内部消息。11 条，占全部工具错误的 6%。

其中 7 条（"Plugin helper is closed"）来自**已退役的 TypeScript 插件宿主**（`src/runtime/durable-plugin.ts:92`），Go 内核路径没有这条消息。另外 4 条（"Runtime is closed" / "Pi host channel closed"）在 Go 侧仍有对应物（`core_task_runtime.go:1654` 的 `ensureOpen`），但那一处是**运行时就该拒绝**的守卫：`Close()` 先 `Drain()` 再释放，晚到的工作被拒是对的。真正要修的是"模型收到这句话却无从判断发生了什么"——修法是让消息说清"宿主已关闭，本次调用未执行"，而不是改关闭顺序。

**不是缺陷但值得记的**：浏览器扩展 36 条错误（占全部的 19%）里，11 条是"临时 profile 目录无权"——**扩展需要的临时目录没有被访问策略授予**。这可能是策略漏了一条路径，也可能是有意的隔离；改它是一次安全决定，所以本轮只记录、不动手。

**"预期"这一类里有价值的部分是错误文本本身**：多数错误点名了缺什么（"graphId: must have required properties"、"Available scripts are: …"、"outputs.result.enable"），模型能据此改对——这是上一轮"错误要可恢复"那条要求的实际效果。
