# App UX 重构：会话优先的工作台

状态：2026-09-16 已在 `feat/app-ux` 实施，等待验收。

GitHub Issue：当前仓库没有 remote，本文件是 Issue 草稿。指定目标仓库后可使用
`ready-for-agent` 标签发布。

## 目标

将 Graph APP 从控制台式首页重构为 ChatGPT 式的会话优先工作台：

- 用户先与主 Agent 对话，确认草稿后才创建并执行正式功能任务。
- 项目与对话成为左侧的主导航结构。
- 任务草稿、任务图、节点和执行进度保留在会话中，但默认为简洁摘要。
- 详细内容进入右侧抽屉，不打断消息流。

本改造复用 ADR 0009 的会话、anchor 任务、提案确认和执行账本，不新增执行通道。

## 信息架构

左侧栏自上而下包含：

1. `Graph` 品牌与“新对话”入口。
2. `问题`：跨项目的全局问题收件箱。
3. `人才库`：Agent 定义与能力。
4. `项目`：每个项目一行，行右侧的加号在当前项目新建对话；项目下显示该项目的对话。
5. `最近`：所有未绑定项目的对话；绑定项目后，对话自动移动到对应项目下。
6. `设置`：固定在底部，连接配置向导并入设置页。

主区域：

- 未进入会话时显示新对话编辑器。
- 进入会话后显示当前对话标题、消息流和底部固定发送框。
- 用户消息右对齐，主 Agent 消息左对齐。

## 会话内容

- 草稿、任务图和任务状态以摘要卡出现在消息流中。
- 摘要卡显示范围、验收项数量与节点状态，不在主消息流堆叠完整执行明细。
- 点击摘要卡中的详情入口后，在右侧抽屉显示验收项、节点、任务图、目标分支、集成提交和用量。
- 待处理问题仍可从全局收件箱处理；与会话或任务直接相关的问题同时出现在对应摘要卡内。
- 未绑定项目的会话显示绑定入口；绑定成功后侧栏位置自动更新。

## 视觉约束

- 仅提供浅色主题，不提供暗黑模式或主题切换。
- 背景 `#FFFFFF`，前景 `#1A1C1F`。
- UI 基准字号 `14px`，代码字号 `12px`。
- 使用白色、浅灰边界与克制的状态色，不再使用深色侧栏。

## 交互细节

- 左侧栏是可收回的抽屉；顶部提供抽屉按钮，折叠后保留图标导航。
- “项目”标题右侧提供新建项目按钮，打开创建项目弹窗。桌面 APP 通过本机目录选择器选择源文件夹，浏览器模式允许直接填写路径。
- “设置”固定在左侧抽屉底部；不再显示执行模式状态。
- 主 Agent 一轮中的工具调用位于最终回答之前，最终回答收束该轮消息。
- 主 Agent 消息按安全的 Markdown 子集渲染，支持标题、段落、粗体、强调、列表、引用、代码和链接；不执行原始 HTML。
- 右侧详情抽屉可在会话顶部和抽屉右上角通过抽屉图标展开或收起。

## 验收项

1. 根路径只提供新对话入口，不再显示“提交新任务”和“任务队列”。
2. 侧栏不再显示“概览”和“向导”；设置固定在底部。
3. 项目行右侧加号会打开预选该项目的“新对话”。
4. 未绑定会话位于“最近”，绑定后出现在项目下且从“最近”消失。
5. 对话显示自身标题；消息按用户右侧、主 Agent 左侧显示。
6. 草稿和任务在消息流中只显示摘要；点击后右侧抽屉展示完整详情。
7. 问题页继续跨项目聚合所有未处理的正式任务问题。
8. 旧的任务页、任务图、节点详情、问题答复、分页、暂停和恢复行为保持可用。
9. 设置页包含连接与配置向导。
10. 浅色主题在首次启动时直接生效，不读取或切换暗黑模式。
11. 左右抽屉都可独立展开和收起。
12. 可通过侧栏新建入口选择本地目录并创建项目。
13. 工具调用显示在主 Agent 最终回答之前。
14. 主 Agent 回答按 Markdown 渲染，且原始 HTML 不执行。

## 第二轮细节调整

第二轮继续沿用会话优先结构，补齐聊天运行指标、资源组织和设置页信息架构：

- 会话底部输入框右侧显示缓存命中率、最近一次请求的上下文窗口占用、当前主管模型和思考强度。指标来自主管实例的真实 invocation 账本；没有权威记录时显示 `—`，不折算为零。当前 Pi 内核的思考强度实际固定为关闭。
- 左栏 `人才库` 更名为 `资源库`。资源库分为 Skills 库、MCP 库、Agent.md 库、Agent 组合库，并保留 Agent 组合的版本与经历详情。
- 资源库新增架构库，列出顺序执行、条件路由、扇出与汇合、流水线、主管与工人、评估与优化、对抗式验证、多视角与评委等经典 Graph 架构。
- 问题收件箱继续展示待处理问题，同时从真实 question 账本读取 `resolved` 记录，按处理顺序展示历史。
- 设置改为第二页面：左侧为搜索与设置导航，右侧为详情，左上角返回应用。连接与配置向导仍并入设置。

第二轮补充验证：

- 会话 telemetry 会从真实主管 invocation 的 cache/input/context 用量生成，并受配置的 contextWindow 限制。
- 收件箱历史在主流程完成问题答复后可见。
- 设置页在宽屏和窄屏均无横向溢出。
