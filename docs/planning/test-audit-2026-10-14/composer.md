Blanks cannot be submitted.

Assert chip plus actual POST body or provider request, not helper objects. Empty FileReader data URL is not externally achievable without mocking browser; delete implementation-only half of NUL/empty-image declaration while keep NUL guard.

Real editor bounding/scroll geometry with empty, multiline and long draft; no copied helper constant expectations. Tests of custom line height/maximum and NaN are pure helper seam with no caller, delete.
5. Pause/queue/scroll: use real server/public HTTP paused state and deferred real provider response. Primary button pauses while active irrespective typed/queued content, resumes empty pause, sends input or queue and resumes, disables during in-flight request. Idle suggestion/queue already covered app-shell-ux 653 but route mock duplicates state: extend genuine HTTP/Pi flow. ### 流式链路直接源码证据

`src/runtime/worker-requests.ts` 的 model/events 分支先 `await encodeAssistantStream(stream)`，随后 `await stream.result()`，才返回 frames+settlement。`src/runtime/pi-worker.ts` 先等待完整 broker request，然后同步 replayAssistantStream。`assistant-stream-frames.ts` 的 encoder 持续遍历直至外部流结束才返回帧数组。因此模型 TCP 响应中途暂停时，conversation 正式 stream 尚未收到 worker replay；公开 streams 为空符合当前实现，不能凭延长等待修正。这改变下一步：必须分别验证实际终态事件回放/浏览器渐显与真正即时传输契约；若要求后者，需要在真实 worker IPC owner 引入流帧传递，并提供主会话及常驻进程的因果控制，不能修改复制测试以制造即时流。旧 streaming-copy 与真实会话 stream 契约继续保留，当前 keeper 尚未过关。

### 复制 keeper 的实际产品边界

真实外部模型响应未完成时，当前 production IPC 尚未公布 assistant stream；UI 显示“正在思考…”。新增 E2E 直接断言该实际待完成状态下 assistant/streaming 区没有复制入口，并断言真实工具行无复制按钮，然后放行同一模型响应并核对最终 Markdown 的精确剪贴板字节、用户源文本、插入/选择粘贴及真实权限拒绝。该 keeper 不再要求一个当前实现不会产生的中途 stream DOM 行。它证明用户可观察的“未完成回答不能复制”，不声称修复即时流式传输；原 helper 的显式 streaming row 拒绝契约仍保留直到对应实际事件回放/显示边界补证。
