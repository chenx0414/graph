# 能力按定义版本在受限边界内加载

Agent 定义版本绑定能力 ID 与版本。生产实例打开时按绑定解析并加载这些能力，而不是只在任务说明里列出 ID：

- Skill 作为 Pi 资源加载器中的只读资源进入系统提示，模型可通过工作区读取入口读取快照内文件。
- MCP 通过真实 stdio JSON-RPC 暴露工具；每次调用启动一个操作系统受限进程，经与模型请求相同的 send gate，因此调用可计量、暂停时不会启动新进程，且写入范围不超出工作副本与 Graph scratch。
- 扩展不在正式后台进程加载，绑定到扩展的定义以具体原因阻塞，等待受限 worker 内的扩展加载方案。

能力加载不写入 `task_grants`，安装能力也不会扩大任务权限。相比把能力 ID 写进说明包或让主管在后台进程直接加载扩展，这一选择要求更多受限进程与协议代码，但保住了“安装不等于授权”和批量暂停、记账、恢复规则的一致性。远程 MCP 的域名白名单与扩展的受限加载仍未完成，不因本决定标为已交付。
