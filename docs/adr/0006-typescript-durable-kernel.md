# TypeScript 执行内核持有唯一正式状态

实现规划采用 TypeScript 自有持久状态机解释版本化任务图，以 SQLite 保存正式状态、预算和外部操作记录，Pi 负责独立 Agent 会话。首版不引入 LangGraph 或 Rust，全部已确认图模式仍由统一内核支持。

LangGraph 的动态路由、检查点和中断有可用能力，但稳定 Agent 身份、执行中业务图修订、每调用准入及外部效果核查仍需 Graph 自行负责；引入它会增加一套调度状态的协调。选择自有内核承担图激活与恢复实现成本，换取权限、预算与正式状态的集中管理。三个接口候选和一手来源见 [架构比较](../architecture.md#三种接口方案的比较)。
