# Domain docs

## 布局

采用 single-context：
- 根目录 CONTEXT.md：领域术语表。
- docs/adr/：架构决策记录。

文件按需创建：术语明确时建立术语表，重要权衡确定后记录 ADR。

## 消费规则

探索代码前，读取 CONTEXT.md 以及与当前主题相关的 ADR。
文件不存在时直接继续。

在任务、设计、代码与测试中，使用术语表定义的领域名称。
遇到术语缺口，在领域建模讨论中澄清。

CONTEXT.md 仅记录领域术语与关系。
实现细节和规格放入相应设计文档或任务。

提出与现有 ADR 冲突的方案时，明确指出对应 ADR、
冲突内容与重新考虑的理由。
